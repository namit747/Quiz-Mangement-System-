# Quiz Management System

A simple Quiz Management System built in Python as a personal practice project. This application allows users to add questions, take randomized quizzes, view score history, and review incorrect answers. I built this project to strengthen my understanding of Python fundamentals and gain hands-on coding experience.

## Features

* Add new quiz questions
* Store questions in a text file
* View all available questions
* Randomized quiz order using `random.shuffle()`
* Score calculation and percentage display
* Score history saved to a file
* Review incorrect answers after completing a quiz
* Menu-driven interface

## Project Structure

```text
QuizApp/
│
├── main.py
├── questions.txt
└── scores.txt
```

### Files

* **main.py** – Contains the entire application logic.
* **questions.txt** – Stores quiz questions and answers.
* **scores.txt** – Stores previous quiz scores.


```bash

```

3. Run the program:

